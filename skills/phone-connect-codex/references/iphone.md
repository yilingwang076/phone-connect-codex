# iPhone：使用 Mac 的“iPhone 镜像”

此流程使用 Mac 自带的“iPhone 镜像”App，**不要求 USB、ADB 或 scrcpy**。它通过无线连续互通连接附近的 iPhone。先确认当前执行环境能操作用户的 Mac；云端环境不能代替用户打开本地 App。

1. 优先使用可用的电脑 UI 工具，按 bundle ID `com.apple.ScreenContinuity` 获取“iPhone 镜像”App；如果已打开就复用，未打开则启动。观察 App 的窗口和截图，确认是正在镜像、等待连接、需要认证，还是报错。不要仅凭进程存在就称连接成功。
2. 按窗口提示完成连接。若需要在 iPhone 上输入密码、在 Mac 上认证，交由用户在对应设备完成；不要索取或猜测密码。若显示多台可选 iPhone，先请用户选择，不擅自更改系统的默认设备或认证设置。
3. 只有窗口**实际显示 iPhone 屏幕**时才报告接入成功，并描述当前界面。若无法连接，先看错误提示；可检查 Apple 官方列出的前提：兼容的 macOS/iOS、同一 Apple 账户、蓝牙与 Wi-Fi、iPhone 在附近且锁定。不要为测试自动更改账户、安全或网络设置。
4. 后续操作以最新窗口截图与可访问元素为依据。优先点击可访问元素；需要坐标时依据当前截图尺寸、方向和控件位置，不保存通用坐标。每次关键操作后重新观察。使用电脑 UI 工具提供的 `scroll` 滚动，不把拖动手势当作通用滚动。可使用镜像窗口的主屏幕与 App 切换器按钮，或其已确认可用的键盘快捷键。
5. 连接中断、镜像暂停、iPhone 被解锁、受保护内容无法显示或输入受限时，先重新观察窗口并说明情况，不连续盲点。不要改用 iPhone USB 调试之类不存在的安卓流程。

官方参考：[Apple《iPhone 镜像：通过 Mac 使用 iPhone》](https://support.apple.com/zh-cn/120421)。该功能是否可用由当前设备、系统和地区决定；App 显示的实际状态优先于预设判断。
